# インクリメンタルゲーム市場調査 2025–2026

調査日: 2026-09-18。「眠りの跡」v0.1（クッキークリッカー型）が面白くないという評価を受け、
近年ヒットした作品の「何が独特として機能しているか」を洗い直したもの。

## 1. 結論

2025〜2026年に評価・売上を伸ばした新作は、ほぼ例外なく **「行為（動詞）が主役で、数字インフレはその行為を派手にする演出」** という構造をしている。
「一覧から生産設備を買い足す」クッキークリッカー型の新作ヒットは、この2年間ほぼ存在しない。

補助的な共通項:

- プレイ時間 2〜8 時間で **明確な終わり** があり、任意で無限モードが続く
- 画面そのものが進行につれて「育つ・埋まる・派手になる」
- 戦略が途中で入れ替わる（序盤の最適解が終盤に無価値になる）
- プレステージは「必須の作業」ではなく「新システムが開く節目」

日本語圏でも同じ傾向が指摘されている（apisiva「2025年の隠れブーム」）:
「放置する時間はあまりなく、せわしなくクリックしてる時間が多い」「序盤の地味さから終盤の派手さへの落差」「2〜5時間で完全な達成感」。

## 3. 成功作に共通する5つの設計

1. **動詞が先、数字は後**: 最初の10秒に手触りのある行為がある（削る・叩く・撃つ・投げる・潜る）。
   数字はその行為を強く・速く・派手にするために存在する。
2. **画面が育つ**: 進行が数字ではなく画面の密度・速度・破壊規模として見える（Gnorp、Trainatic、To the Core の処理落ち）。
3. **戦略の入れ替わり**: 序盤の正解が後半で無価値になる（Gnorp）、資源が枯れる（Sixty Four）、
   リセットごとに新しい系統が開く（Tower Wizard）。同じ手が通用し続けると「スプレッドシート化」する。
4. **終わりがある**: 3〜8時間で「終わった」と言える設計がレビューで一貫して賞賛される。
   無限モードは「終わったあとのおまけ」として付く。
5. **一文で説明できるコンセプト**: 「くじを削る」「貯金箱を叩く」「ベリーを穴に捨てる」。
   テーマが行為に直結しているため、説明＝魅力になる。

## 4. 失敗要因（コミュニティの批判）

- 「ボタンを押して待つだけ」で新要素が来ない → 飽きる
- プレステージの増分が小さく、同じ戦略の繰り返しになる
- 数字管理だけになり「ゲームからスプレッドシートへ」移行する
- テーマが表層に留まり、序盤が汎用クリッカーに見える（gamedeveloper.com の開発後記と同じ失敗）

## 5. 「眠りの跡」v0.1 の診断

- 動詞が「一覧のボタンを押す」しかない。夢というテーマは名前と背景色にしか現れていない
- 画面が育たない。階層が増えてもカードが縦に増えるだけ
- 戦略の入れ替わりがない。常に「安い住人から買う」が正解
- 終わりがなく、無限に薄く続く

つまり §3 の5項目すべてを満たしていない。数値調整では直らず、コアの動詞を決め直す必要がある。

## 6. 再設計の方向性（候補）

いずれも「夢」テーマを行為に落とし込む案。

### A. 潜る（To the Core / Nodebuster 型）
夢の底へ向かって実際に降下する。眠気（エネルギー）が尽きると目覚めてラン終了、
持ち帰った記憶で次のランは速く深く潜れる。深層ほど時間加速で落下速度が上がり、
画面の流速と密度が上がる。悪夢は降下中の障害物として登場する。
一文: 「眠気が尽きるまで夢の底へ落ち続ける」。

### B. 夢を編む（Sixty Four 型）
夢の断片を盤面に配置し、隣接関係で記憶が育つ配置パズル。
思考型で「放置」寄り。行為の手触りは弱いが戦略の入れ替わりを作りやすい。

### C. 悪夢を祓う（Gnorp 型）
画面に湧く悪夢を、夢の住人たちが群れで押し返す群衆シミュレーション。
プレイヤーは住人の種類と配置と強化を選ぶ。画面が住人で埋まる演出が作れる。
一文: 「夢の住人を増やして悪夢を押し返す」。

### D. 物語発見型のレイヤー（Berry Bury Berry / Paperclips 型）
上記いずれかに重ねる要素。潜るほど「なぜ眠り続けているのか」が現実側で明かされ、
複数エンディングで「終わり」を作る。

推奨: **A を核に D を重ねる**。夢潜行というテーマ自体が「降下」という動詞を最初から含んでおり、
時間加速＝落下速度、目覚め＝ラン終了、記憶＝永続強化と、既存の設計要素をほぼそのまま
行為ベースに読み替えられる。無限モードは「底に着いた後」に用意する。
